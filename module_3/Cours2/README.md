### Description de la séance

Cette semaine, le dernier module portait sur le web ainsi que la connexion entre des objets physiques et des interfaces numériques.

Une interface écran doit répondre à quatre principes :

- l’écran accomplit un but clair
- l’interface est simple et facile à comprendre
- les éléments interactifs sont mis en valeur
- l’interface réagit à chaque interaction

Les interfaces peuvent être contrôlées par des dispositifs physiques, comme des manettes, des capteurs ou des objets connectés, afin de créer des expériences interactives.

La programmation web repose sur trois langages principaux : HTML, CSS et JavaScript.

> Le HTML est le squelette du Web.  
> Le CSS permet de définir l’apparence du site et d’adapter l’interface à différentes tailles d’écran.  
> Le JavaScript rend le site dynamique et interactif.

Le HTML est organisé en balises : html, head, body, et ils permettent de structurer le contenu en blocs, en titres, en paragraphes, en images et en liens.

> html définit le début et la fin du document.  
> head contient les informations non affichées par le navigateur.  
> body contient tout le contenu visible de la page.

Le Circuit Playground peut transmettre des données provenant de ses capteurs à une interface numérique.
